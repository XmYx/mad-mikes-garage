## Export notes (PIPELINE.md)

- Axes: game (x, y, z) -> Blender (-x, -z, y), the same mapping as `cars/` and `character/` (no `mirroredOnExport`).
- Roots are empties named like the game id at the asset origin; the .blend files keep the preview layout offsets (the exporter resets roots to the origin). World buildings carry the 180 degree preview turn only in the renders.
- Vegetation has a `Sway` point attribute, 0 at the root -> 1 at the tips; the exporter's `Col.a` is the voxel convention (1 = rooted), so write `Col.a = 1 - Sway`.
- Buildings: `Shell_<Material>` (carvable, root prop `shell_parts`), `Detail`, `Glass`; movers (rotors, leaves, stamps, heads) are separate objects with `mover = True` and their pivot at the joint.
- Animals: root empty / `Rig` armature (one bone per part) / part meshes bone-parented; object props `part` (name as in Animal's Rig), `rig_part`, `index`, `pivot_game_m`; root props `ref_height`, `species_name`.
- Emissive lamp materials are named `Lamp*` (white / amber / red) so the exporter's lamp classes pick them up.
